# Blog Commit Message

| 타입 | 용도 |
|------|------|
| `feat` | 새 포스트 작성, 기능 추가 |
| `fix` | 오타, 깨진 링크, 레이아웃 오류 수정 |
| `docs` | README 및 문서 수정 |
| `style` | 마크다운 형식, CSS 스타일 수정 |
| `refactor` | 블로그 구조 및 코드 개선 |
| `chore` | 이미지 정리, 설정 파일 수정, 불필요한 파일 정리 |
| `ci` | GitHub Pages, Actions 배포 설정 수정 |
